# 🏥 MediCare Hospital — Marketing & Patient Portal Frontend

> *"Compassionate Care, Cutting-Edge Technology"*

A modern, responsive, and realistic static marketing website for **MediCare Hospital** (Chennai, Tamil Nadu), built using **React**, **Vite**, **Tailwind CSS**, and **Lucide React**.

---

## ✨ Features & Sections

- **Sticky Responsive Navbar**: Smooth background transition on scroll, 24/7 emergency helpline (+91-1800-MEDICARE), and mobile slide-in drawer.
- **Hero Section**: Healthcare heritage copy since 1998, glowing animated background, and 4 floating stat badges (*25+ Years of Excellence*, *500+ Doctors*, *1M+ Patients Served*, *24/7 Emergency Care*).
- **Announcement Ticker**: Continuous horizontal marquee ticker with COVID vaccination, MRI wing, and clinic updates.
- **Core Hospital Services**: Glassmorphism cards with hover lift and teal glow (*Patient Registration, Laboratory, Pharmacy, Billing, Appointment Management*).
- **Animated Stats Strip**: Full-width teal banner with dynamic count-up animations on scroll.
- **About MediCare**: Chennai hospital campus story with NABH, ISO 9001:2015, and JCI accreditation badges.
- **Specialist Grid**: 4 doctor cards with 3D flip-card interaction displaying qualifications, consultation timings, and booking buttons.
- **Patient Testimonials**: 3-second auto-rotating carousel with pause-on-hover and star ratings.
- **Contact Desk & Map Placeholder**: Comprehensive contact details, Anna Salai address, emergency lines, and an interactive enquiry form with feedback toast.
- **Appointment Dialog**: Accessible informational modal for quick booking.

---

## 🛠️ Tech Stack

- **Framework**: React 18
- **Build Tool**: Vite 6
- **Styling**: Tailwind CSS 3
- **Icons**: Lucide React

## 🚀 Getting Started Locally

### Prerequisites

Ensure you have **Node.js** (v18 or newer) installed:
```bash
node -v
npm -v
```

### 1. Clone the repository
```bash
git clone https://github.com/<your-username>/medicare-hospital.git
cd medicare-hospital
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run the development server
```bash
npm run dev
```

Open your browser and navigate to:
```
http://localhost:5173
```

### 4. Build for production
```bash
npm run build
```
The optimized production output will be in the `dist/` directory.
